# Expense Tracker Currency PWA

โปรเจกต์นี้สร้างจากหน้า Expense Tracker ต้นแบบของผู้ใช้ โดยคงหน้าตาและการทำงานเดิมไว้ และเพิ่มโครงสร้าง Progressive Web App (PWA)

## คุณสมบัติ

- แยกค่าใช้จ่ายเป็น `ส่วนตัว` และ `สปอนเซอร์`
- รองรับสกุลเงิน THB, CNY และ HKD
- กำหนดอัตราแลกเปลี่ยนเป็นเงินบาท
- คำนวณยอดเงินบาทอัตโนมัติ
- ถ่ายหรือแนบรูปใบเสร็จ
- บีบอัดรูปก่อนเก็บในเครื่อง
- กรองตามหมวดและเดือน
- ส่งออกข้อมูลเป็น CSV
- ใช้งานออฟไลน์
- ติดตั้งลงหน้าจอหลักได้

## วิธีใช้งาน

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์หรืออัปโหลดขึ้นโฮสติ้ง เช่น Vercel, Netlify, GitHub Pages หรือ Firebase Hosting

### ทดสอบในเครื่อง

```bash
python -m http.server 8080
```

จากนั้นเปิด:

```text
http://localhost:8080
```

## การติดตั้งบนมือถือ

### Android / Chrome

เปิดเว็บไซต์ แตะเมนูสามจุด แล้วเลือก `ติดตั้งแอป` หรือ `เพิ่มไปยังหน้าจอหลัก`

### iPhone / iPad / Safari

เปิดเว็บไซต์ แตะ Share แล้วเลือก `Add to Home Screen`

## ข้อควรระวัง

ข้อมูลและรูปใบเสร็จถูกเก็บใน Local Storage ของเบราว์เซอร์ หากล้างข้อมูลเว็บไซต์ เปลี่ยนเครื่อง หรือลบแอป ข้อมูลอาจหายได้ ควรส่งออก CSV เป็นระยะ
